# Leg notes

Each leg starts on the initial great-circle bearing from $A$ toward $B$,

$$\theta = \operatorname{atan2}\left(\sin\Delta\lambda \cos\varphi_2,\; \cos\varphi_1 \sin\varphi_2 - \sin\varphi_1 \cos\varphi_2 \cos\Delta\lambda\right)$$

normalized to [0°, 360°). On legs this short the
bearing barely drifts, so one heading per leg is
enough.
