# API — ShipTools

```@meta
CurrentModule = ShipTools
```

The `ShipTools` umbrella package. Its public Julia surface is the
installer for the [sot-comm](comm.md) session-to-session messaging system;
the explorer itself runs as the Rust frontend and backend plus the Julia kernel
and plugins, which are described in [Architecture](../guide/architecture.md)
and [The Dispatch ABI](../extend/abi.md).
